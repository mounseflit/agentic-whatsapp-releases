# Agentic WhatsApp: downloads

**Agentic WhatsApp**, made by **Mounsef Litniti**, turns your computer into your own WhatsApp API and dashboard: chats, auto-replies, an AI assistant (Claude), REST API, MCP tools for AI agents and webhooks. It runs on your computer and gives you a private link to open your dashboard from anywhere.

## Windows (10/11, 64-bit)

**[⬇ Download AgenticWhatsApp-Setup.exe](https://github.com/mounseflit/agentic-whatsapp-releases/releases/latest/download/AgenticWhatsApp-Setup.exe)** (~118 MB)

1. Run the installer and follow the wizard.
2. The dashboard opens: scan the QR code with WhatsApp (*Settings → Linked devices → Link a device*).
3. Your private remote link arrives in your WhatsApp "Message yourself" chat.

The app stays in the tray near the clock (open dashboard, copy remote link, start/stop, settings, logs).
The installer is not code-signed yet. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

Setup guide and other install options: https://agentic-whatsapp-mu.vercel.app
